# SQL Sales Analysis

## About This Project

This project demonstrates my SQL skills through the analysis of a sales dataset.

The analysis focuses on customers, products, and sales data to answer business-related questions and generate useful insights.

## Objectives

- Analyse customer purchasing behaviour
- Identify top-selling products
- Calculate total sales and revenue
- Compare sales performance across products
- Practice SQL queries for data analysis

## Key Findings

### 1. Total Revenue

The total revenue generated from the sales dataset was **9,755.00**.

### 2. Revenue by Category

- **Electronics:** 9,050.00
- **Accessories:** 705.00

Electronics generated approximately **93% of total revenue**, making it the strongest-performing product category.

### 3. Top Product by Revenue

The **Smartphone** generated the highest revenue at **3,900.00**.

### 4. Top Customer

**Nuwan Dias** was the highest-spending customer, with total purchases of **2,070.00**.
