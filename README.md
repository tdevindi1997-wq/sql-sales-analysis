# SQL Sales Analysis

## About This Project

This project demonstrates my SQL skills through the analysis of a sales dataset.

The analysis focuses on customers, products, and sales data to answer business-related questions and generate useful insights.

## Objectives

- Analyse customer purchasing behaviour
- Identify top-selling products
- Calculate total sales and revenue
- Compare sales performance across products
- Practice SQL queries for data analysis

## SQL Skills Demonstrated

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- JOIN
- Aggregate functions
- Subqueries
- Calculated fields

## Tools

- MySQL
- MySQL Workbench
- GitHub
